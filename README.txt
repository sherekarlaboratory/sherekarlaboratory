Sherekar Clinical Laboratory - Static Website

Files:
- index.html: Website content and structure
- style.css: Layout, colors, responsive styles

How to view:
1. Keep index.html and style.css in the same folder.
2. Double-click index.html to open it in a browser.

How to publish:
Upload both files to your hosting provider's public website folder (often named public_html).
This is a static website; it does not include online booking, forms, or a database.

Please verify the phone numbers, service availability, and address before publishing.
The website uses an internet connection to load Google Fonts; system fallback fonts are included.
